# AI Lab - Интерактивные демонстрации

Добро пожаловать в AI Lab — пространство для экспериментов с искусственным интеллектом в медицине.

## О лаборатории

AI Lab представляет собой коллекцию интерактивных демонстраций, показывающих практическое применение машинного обучения и искусственного интеллекта в медицинских задачах.

## Доступные демонстрации

### 1. Предсказание послеоперационных осложнений

Интерактивная модель для оценки риска послеоперационных осложнений на основе предоперационных данных пациента.

**Возможности:**
- Ввод клинических параметров
- Расчет индивидуального риска
- Визуализация факторов риска
- Рекомендации по ведению

**Технологии:** XGBoost, SHAP, Gradio

### 2. RAG-система для медицинской литературы

Система для поиска и анализа медицинских публикаций с использованием Retrieval-Augmented Generation.

**Возможности:**
- Поиск по медицинским вопросам
- Генерация ответов с ссылками на источники
- Анализ клинических протоколов
- Сравнение методов лечения

**Технологии:** LangChain, OpenAI, ChromaDB

### 3. Анализ медицинских изображений

Демонстрация применения компьютерного зрения для анализа медицинских изображений.

**Возможности:**
- Сегментация опухолей
- Классификация патологий
- Измерение размеров образований
- Визуализация результатов

**Технологии:** PyTorch, MONAI, Gradio

## Как использовать

Каждая демонстрация представляет собой интерактивное веб-приложение, развернутое на Hugging Face Spaces или локально через Gradio.

### Требования

- Современный веб-браузер
- Интернет-соединение (для онлайн демо)
- Для локального запуска: Python 3.8+, необходимые библиотеки

### Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/Serg2206/ssvproff-surgical-ai-models.git
cd ssvproff-surgical-ai-models

# Установка зависимостей
pip install -r requirements.txt

# Запуск демонстрации
python demos/complications_predictor.py
```

## Образовательные цели

AI Lab создан для:

1. **Демонстрации возможностей ИИ** — показать, как AI может помочь в медицинской практике
2. **Обучения** — помочь врачам и студентам понять принципы работы AI
3. **Исследований** — предоставить инструменты для экспериментов
4. **Вдохновения** — стимулировать разработку новых AI-решений в медицине

## Ограничения и предупреждения

⚠️ **Важно:**

- Демонстрации предназначены только для образовательных целей
- Не используйте для принятия клинических решений без консультации с врачом
- Модели обучены на ограниченных данных и могут быть неточными
- Всегда проверяйте результаты с медицинскими специалистами
