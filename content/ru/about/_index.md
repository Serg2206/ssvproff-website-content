# О себе

## Сергей В. Сушков

Хирург, научный исследователь и разработчик, специализирующийся на применении искусственного интеллекта в медицине.

### Образование

- **Медицинский университет** — специальность "Лечебное дело"
- **Ординатура** — хирургия
- **Дополнительное образование** — искусственный интеллект, машинное обучение, анализ данных

### Профессиональный опыт

#### Клиническая практика
- Хирургия общего профиля
- Онкохирургия
- Криотерапия в лечении опухолей
- Малоинвазивные хирургические вмешательства

#### Научная деятельность
- Исследования в области хирургической онкологии
- Разработка методов криотерапии
- Применение ИИ для предсказания послеоперационных осложнений
- Создание RAG-систем для медицинских данных

#### Технологическая экспертиза
- Разработка AI-моделей для медицинских приложений
- Анализ больших медицинских данных
- Создание интерактивных образовательных платформ
- Интеграция ИИ в клиническую практику

### Области интересов

- **Хирургическая онкология** — современные методы лечения злокачественных новообразований
- **Криотерапия** — применение экстремально низких температур в онкологии
- **Искусственный интеллект** — машинное обучение, глубокое обучение, NLP в медицине
- **Цифровое здравоохранение** — телемедицина, электронные медицинские записи, аналитика данных
- **Медицинское образование** — разработка образовательных материалов и платформ
